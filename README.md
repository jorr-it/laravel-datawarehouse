# Laravel Datawarehouse

With Laravel Datawarehouse you can make your own datawarehouse. Features:
- Transformations look like migrations and can be used to create FactModels and DimensionModels
- Use Eloquent to query your datawarehouse
- Flow PHP is integrated for ETL processes
- Define the DimensionModel's SCD type and all required fields are added automatically
- Aggregated FactModels will be filled and updated automatically
- MySQL, PostgreSQL, Azure Database/Synapse and Snowflake will be supported
- Also supports Doctrine
